# Book Lending

Book Lending App : Users log in as either a Member or an Admin. Admins add, edit and delete books (title, author, copies), and members can search and browse what’s available. A member borrows a book, which sets a 14-day due date, and the admin marks it returned, which updates the copy count. A simple dashboard shows members their current loans and shows admins every active and overdue loan. It needs three tables: Users, Books and Loans.

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Vite + React SPA. Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- a FastAPI service. No architecture had been approved
  when this repository was created, so it starts with its health check and
  nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
pytest
ruff check .
ruff format .
```
